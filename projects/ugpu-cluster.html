System Pipeline Architecture

Hierarchical Data Flow (Architecture)
Phase 1: Instruction & Data Broadcast
Phase 2: Warp Sync Trigger
Phase 3: Pipelined Execution
Phase 4: Push-Based Memory Access
Phase 5: Write Back
A

Host System (Layer 0)

PyTorch models are compiled into Binary Blobs. The host tiles large tensors into small chunks (Grid Tiling) and streams instruction packets via USB.

B

Grid Dispatch (Layer 1)

The AMB82 Master receives packets and uses its DMA Engine to drive the Global 8-bit Bus at 50MB/s, broadcasting data to the chosen Streaming Multiprocessor (SM).

C

Warp Scheduler (Layer 2)

The ESP32 SM buffers data in L1 PSRAM. It decodes instructions and orchestrates a 'Lockstep Launch', triggering all 4 RP2040 cores simultaneously via the SYNC_TRIG signal.

D

SIMT Thread Execution (Layer 3)

Each RP2040 executes the same kernel on different data (SIMD). The Dual-Core architecture allows overlapping Compute (Core 0) and Memory Fetch (Core 1).
