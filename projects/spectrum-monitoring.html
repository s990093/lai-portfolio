Spectrum Monitoring:
Etching Plasma Analysis

A Transformer-based time-series classification model for identifying semiconductor etching process stages and detecting anomalies from OES big data. Achieved 96.44% accuracy and developed a cross-platform monitoring app.

01. Research Purpose

Optical Emission Spectroscopy (OES) is a critical non-invasive monitoring tool in etching processes. However, the sheer volume and complexity of OES data make manual analysis inefficient.

For instance, identifying stable regions (e.g., 80–180s) in thousands of waveforms is challenging. This research aims to automate this process using deep learning to enhance monitoring efficiency and precision.

02. Methodology

Data Preprocessing

Raw signals (F, Ar, SiF) undergo smoothing to remove high-frequency noise, followed by Min-Max normalization to scale values to [0,1][0, 1][0,1]:

X′=X−min⁡(X)max⁡(X)−min⁡(X)X' = \frac{X - \min(X)}{\max(X) - \min(X)}X′=max(X)−min(X)X−min(X)​

Data is then sliced into fixed-length sequences and labeled with process stages: PRE-CLEAN, RAMPING, DEPOSITION, POST-DEPO.

Transformer Model

We designed a time-series classification model based on the Transformer architecture. It features a 2-layer, 4-head Encoder to extract temporal features, followed by Self-Attention Pooling for sequence summarization.

04. Application Implementation

To facilitate real-time monitoring on the factory floor, we developed a cross-platform desktop application.

System Architecture

  • Backend: Flask + PyTorch for model inference.
  • Frontend: Electron + Node.js for a responsive desktop UI.
  • Features: Real-time waveform visualization, stage prediction, and anomaly alerts.
